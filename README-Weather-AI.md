# 🌦️ Weather AI

A browser-based weather application built with **HTML, CSS, and JavaScript**. This project provides a front-end interface for displaying weather information.

## 📌 Project Overview

Weather AI is a web development project focused on presenting weather information through a simple user interface. The repository separates the page structure, styling, and JavaScript behavior into individual files.

## ✨ Features

- Weather application user interface
- HTML page structure
- CSS styling and layout
- JavaScript for application behavior

> The screenshot shows the project files but not the implementation. Confirm the API provider, search functionality, displayed weather fields, and error handling in `script.js` before claiming them as completed features.

## 🧰 Technologies Used

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript** — interactive behavior and weather-data handling, depending on the implementation

## 📁 Project Structure

```text
weather-AI/
├── index.html   # Main web page
├── script.js    # JavaScript application logic
├── style.css    # Styles and layout
└── README.md    # Project documentation
```

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rushikesh-196/weather-AI.git
   ```

2. Open the project folder:

   ```bash
   cd weather-AI
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and run it using a local development server.
